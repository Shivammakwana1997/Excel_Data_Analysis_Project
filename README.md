# Excel for Data Analytics

Learn Excel step by step for data analysis, from beginner basics to advanced reporting and modeling.

## About this course
This course teaches how to use Excel for real-world data analysis with practical examples, datasets, and projects.

## What you'll learn
- Excel basics.
- Formulas and functions.
- Charts and dashboards.
- Pivot tables.
- Power Query.
- Power Pivot and DAX.

## Course roadmap
1. Spreadsheets Intro
2. Formulas & Functions
3. Charts
4. Advanced Spreadsheets
5. Pivot Tables
6. Advanced Data Analysis
7. Power Query
8. Power Pivot
